Testnet wallet

Make a wallet in this browser tab and fund it with free testnet DNDR. Then send DNDR, or have a miner's Final Testnet Season rewards paid to this wallet.

Chain: testnet

Go to the wallet ↓
  • Testnet only. DNDR is Dendra's utility token, used to pay for AI answers and reward the miners who compute them. There is no token sale, presale or ICO. On dendra-testnet, a public testnet, it is free and never sold.
  • Resettable. A reset erases every balance, yours included. The published Final Testnet Season rankings are archived first.
  • Points come only from the season. Free DNDR, or DNDR from a transfer, is not a point. Only Final Testnet Season rewards, paid by a published formula, count as points: each testnet DNDR the season paid becomes one mainnet DNDR, credited in the mainnet genesis to the address that received it; mainnet launches after the Final Testnet Season.
  • No account. There is no password and no recovery service. The 24 words, your recovery phrase, are the wallet: once this tab is closed or reloaded, they are the only way back into it.

How it works

  1. Create: 24 random words make your key. Write them on paper now.
  2. Your address: it starts with dendra1. Copy it.
  3. Fund it with free testnet DNDR from the faucet.
  4. Use it: send DNDR, or receive a miner's season rewards at this address.

3Get free testnet DNDR

A new wallet holds nothing. The public faucet gives free testnet DNDR for a short computation your computer runs (a proof-of-work), which makes mass claims costly. It runs in a terminal, not on this page.

  1. Copy your address (step 2).
  2. Use a terminal on Linux or macOS, or the WSL Linux terminal on Windows (not PowerShell), with curl and Python 3. Open the command below and run its curl line alone: it prints the amount and the difficulty (pow_bits). Then put your address in ADDR and that number in BITS, and run the rest.
  3. Refresh the balance and trust it, not the faucet's reply: the faucet uses plain HTTP, so its reply is not authenticated.
Show the command
Faucethttp://testnet-api.dendranetwork.com:4500
# 1. Run this line alone: it prints the amount and pow_bits.
curl -s http://testnet-api.dendranetwork.com:4500/
# 2. Set ADDR and BITS below, then run the rest.
python3 - <<'EOF'
import hashlib, itertools, json, urllib.request
ADDR = "dendra1..."          # your address, copied above
BITS = 20                    # pow_bits, as reported by the line above
for n in itertools.count():
    h = hashlib.sha256(("%s:%d" % (ADDR, n)).encode()).digest()
    if int.from_bytes(h, "big") >> (256 - BITS) == 0:
        break
req = urllib.request.Request("http://testnet-api.dendranetwork.com:4500/",
    json.dumps({"address": ADDR, "pow": str(n)}).encode(),
    {"Content-Type": "application/json"})
print(urllib.request.urlopen(req).read().decode())
EOF

Only a public address and a number travel to the faucet. A refusal says why; the limits are in the Docs.

4Send DNDR

The memo is written on the chain: public and permanent. An address can send only after it has received DNDR.

Signs for chain-id?

The chain-id names the network; this page reads it from the chain endpoint, the server it talks to. A transfer is signed for that network only: while it shows “?”, Send is refused.

What your wallet sends

  1. Inside this browser tab, the 24 words make the private key, and the key signs each transfer.
  2. Only these go to the chain endpoint (RPC): your address, your public key, and each transfer, sent once unsigned to estimate its fee, then signed. None of them is secret.
  3. The dendra-testnet chain checks each signature.
  4. The 24 words and the private key are never sent.
  5. The Copy button puts the words in your system clipboard, which this page cannot clear.

Checking mode (verification_mode): at 0, several miners answer each job and are compared. At 1, one miner answers, and a sample of jobs is audited by a jury of miners other than the one under audit. Jury quorum (audit_min_quorum): the fewest jurors who must vote for a verdict; 0 selects a default compiled into the chain.
