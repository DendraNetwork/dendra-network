# The image installs exactly these files and nothing else: pip runs with --require-hashes, --only-binary=:all:
# and --no-deps, so a package that is not listed here, a version other than the one named, or a file whose
# SHA-256 is not listed stops the build. Each line carries the hashes of the wheels for linux/amd64 and
# linux/arm64 (a pure Python wheel has a single hash, shared by both).

# The top-level packages are the three the miner imports, named in docker/miner-requirements.in: cryptography,
# requests and prometheus_client. The other six are their dependencies. The versions are those the image
# installed before the lock existed.

# To move a version: download the wheels with the pip of the base image the Dockerfile pins, once natively for
# linux/amd64 and once with --platform for the manylinux aarch64 tags, write each line as name==version followed
# by one --hash=sha256:<hex> per wheel, and rebuild the image.
